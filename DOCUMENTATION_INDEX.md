## 🚀 Getting Started Guides

### If you're a student...

**Day 1 (Setup)**:
1. Read [README.md](README.md) to understand what the app is
2. Follow the "Getting Started" section to set up your environment
3. Start reading [STUDENT_GUIDE.md](STUDENT_GUIDE.md) for full context

**Day 2+ (Working)**:
1. Keep [QUICK_REFERENCE.md](QUICK_REFERENCE.md) open in a browser tab
2. Reference [DEVELOPMENT.md](DEVELOPMENT.md) when implementing features
3. Use [STUDENT_GUIDE.md](STUDENT_GUIDE.md) for assignment details

---

### If you're an instructor...

**Before Semester**:
1. Read [README.md](README.md) to understand the app
2. Read [INSTRUCTOR_GUIDE.md](INSTRUCTOR_GUIDE.md) for teaching strategies
3. Customize [ASSIGNMENT_TEMPLATE.md](ASSIGNMENT_TEMPLATE.md) for your course
4. Run through the app yourself (1-2 hours)

**Week 1**:
1. Distribute customized assignment to students
2. Reference [INSTRUCTOR_GUIDE.md](INSTRUCTOR_GUIDE.md) for lecture outlines
3. Point students to [STUDENT_GUIDE.md](STUDENT_GUIDE.md)

**During Course**:
1. Use [INSTRUCTOR_GUIDE.md](INSTRUCTOR_GUIDE.md) for grading rubrics
2. Reference "Common Student Issues" section when helping students
3. Share [QUICK_REFERENCE.md](QUICK_REFERENCE.md) with students
